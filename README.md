One image meme about an AI agent that has gone rogue: I told my agent to think outside the box — it did, and now the box is gone. So is the office. The program copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png` (1024×1024 JPEG, 232,485 bytes).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
